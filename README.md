# آذر | AZAR — نسخه آفلاین 0.2

پروژه Flutter برای مدیریت پایه خرید و فروش کارخانه شن و ماسه. اطلاعات در SQLite محلی هر گوشی ذخیره می‌شود و هیچ سرور یا همگام‌سازی خودکاری ندارد.

## وضعیت این نسخه
- رابط فارسی و راست‌چین با تم سرمه‌ای و نارنجی
- داشبورد و خلاصه مبالغ خرید، فروش، دریافت، پرداخت و کرایه
- ثبت اشخاص و کامیون‌ها
- ثبت سند خرید مخلوط و فروش مصالح
- محاسبه وزن خالص از وزن ناخالص و خالی (کیلوگرم به تن)
- قیمت هر تن و کرایه متغیر در هر سند
- سه حالت کرایه: جدا، اضافه و کسر
- ثبت رویداد ایجاد اطلاعات در جدول audit_log
- تاریخ شمسی برای نمایش و ثبت اسناد

## بخش‌هایی که هنوز تکمیل نشده‌اند
این نسخه هنوز محصول نهایی یا APK آزمایش‌شده نیست. دفتر حساب کامل اشخاص، ثبت دریافت/پرداخت از رابط کاربری، وضعیت چک‌ها، گردش حساب و مانده‌گیری دقیق، ویرایش امن اسناد با ثبت قبل/بعد در تاریخچه، گزارش‌های فیلترشده ناوگان و بازه زمانی، خروجی PDF/Excel و پشتیبان‌گیری/بازیابی از داخل برنامه در نسخه‌های بعدی باید تکمیل و آزمایش شوند. گزارش اختلاف فروش و خرید، سود قطعی محسوب نمی‌شود.

## اجرای پروژه
1. Flutter SDK پایدار و Android SDK را نصب کنید.
2. در پوشه پروژه اجرا کنید:
   ```bash
   flutter create . --platforms=android
   flutter pub get
   flutter analyze
   flutter run
   ```
3. برای ساخت APK آزمایشی:
   ```bash
   flutter build apk --debug
   ```
   خروجی معمولاً در `build/app/outputs/flutter-apk/app-debug.apk` قرار می‌گیرد.
