# بارگذاری پروژه آذر در GitHub با گوشی

1. فایل ZIP پروژه را از حالت فشرده خارج کنید.
2. در مرورگر وارد مخزن `habd5800/AZAR` شوید.
3. گزینه **Add file** و سپس **Upload files** را انتخاب کنید.
4. همه فایل‌ها و پوشه‌های داخل `AZAR_v0.2` را انتخاب و بارگذاری کنید؛ خود پوشه مادر را به‌عنوان یک فایل ZIP بارگذاری نکنید.
5. در پایین صفحه یک پیام مانند `Add AZAR offline Flutter source v0.2` بنویسید و **Commit changes** را بزنید.

اگر بارگذاری پوشه‌ها با مرورگر گوشی سخت بود، از GitHub Desktop یا ترمینال کامپیوتر استفاده کنید. فایل ZIP برای نگهداری و انتقال است؛ برای اینکه GitHub کدها را نمایش دهد، باید محتویات آن استخراج و بارگذاری شوند.
